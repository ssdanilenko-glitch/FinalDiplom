# Лимиты API

Публичный API доступен по ключу, который создаётся в разделе «Настройки» → «API-ключи». Ключ передаётся в заголовке `Authorization: Bearer <token>`.

Базовый лимит — 100 запросов в минуту на один ключ. При превышении API возвращает HTTP 429 с заголовком `Retry-After`, указывающим, через сколько секунд можно повторить запрос. Списки возвращаются постранично, по 50 элементов на страницу; следующая страница запрашивается параметром `cursor` из ответа.
