# Двухфакторная аутентификация

Двухфакторная аутентификация (2FA) включается в разделе «Профиль» → «Безопасность» → «Двухфакторная аутентификация». Поддерживаются приложения-аутентификаторы (Google Authenticator, 1Password, Authy), которые генерируют одноразовый код по стандарту TOTP.

При включении 2FA выдаётся 10 резервных кодов — их нужно сохранить в надёжном месте: они позволяют войти, если телефон недоступен. Администратор рабочего пространства может сделать 2FA обязательной для всех участников в настройках безопасности команды.
