# Интеграция со Slack

Интеграция со Slack подключается в разделе «Интеграции» → «Slack» → «Подключить». Потребуются права администратора рабочего пространства Slack для авторизации.

После подключения уведомления о событиях (новая задача, упоминание, изменение статуса) приходят в выбранный канал Slack. Канал и набор событий настраиваются в той же карточке интеграции. Одно рабочее пространство можно связать только с одним workspace Slack; для смены нужно сначала отключить текущую интеграцию.
